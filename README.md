# 油站补油排程台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- 油站维护当前库存与**安全库存**；派车登记油罐车编号、预计到站时间、计划卸量。
- 有未到站车辆时该站显示**待卸**，派车下拉中禁用，不再重复派车。
- 库存按在途计划卸量预估（预估库存 = 当前库存 + 在途量）；预估库存低于安全库存时显示预警。
- 超过预计到站时间 2 小时仍未到场，可**改派新车**：旧调度单记为失约并保留，车辆台账累计失约次数。
- 到站登记实际卸量；实卸不足计划时记**当天差异**并继续预警，处理后可标记已处理。
- 所有记录（油站、调度单、差异、车辆台账）保存在浏览器 localStorage。

## 代码分层

- `src/domain/scheduling.ts`：排程规则（待卸/超时/预估库存/改派/差异，纯函数）
- `src/data/fleet.ts`、`src/data/storage.ts`：车辆台账与本地存储
- `src/App.vue`：页面交互
